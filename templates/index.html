Dental X-Ray Cavity Detection

This web application detects possible dental cavities from dental X-ray images using advanced Image Processing techniques. The uploaded X-ray undergoes Gray Scale Conversion, Thresholding, Edge Detection and Contour Analysis before highlighting the possible cavity region. The application provides a clear visualization of every processing stage along with the final diagnosis result.

Processing Steps

Gray Scale

Converts the uploaded image into grayscale for easier processing.

Threshold

Segmentation separates cavity regions from surrounding teeth.

Edge Detection

Detects boundaries using Canny Edge Detection.

Contour Analysis

Detects possible cavity regions from contours.

Final Detection

Displays highlighted cavity area with diagnosis.

About This Project

This project is developed to identify possible dental cavities from dental X-ray images using Image Processing techniques. The application performs multiple processing stages including grayscale conversion, thresholding, edge detection and contour analysis to visualize potential cavity regions.

It provides an easy and interactive way to understand every processing stage while displaying the final diagnosis result in a professional interface.
